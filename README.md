# Next-word-prediction
Next-word prediction on quotes using RNN, LSTM, and GRU models, with a Streamlit web app that suggests likely next words and generates text continuations. The GRU model is deployed in the app, and the notebooks compare all three architectures.
Source: Tensorflow Quote Dataset. 
Download all (.py, .ipynb, .pkl, .h5) files in a folder In RNN_IMDB.ipynb file, go to terminal and run streamlit To run streamlit, go to terminal of the .py file and enter            py -m streamlit run "file_location\next_word_predict.py" 
For example, in my device I enter:            py -m streamlit run "L:\Softwares\VS Code\Files\RNN\rnn_quote\next_word_predict.py"
A localhost appears in your default web browser and finally you are about to predict next word on the basis of your own description/sentence.
